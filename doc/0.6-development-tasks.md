# AI Token League 0.6 开发任务

## 0. 范围

0.6 已开启八个产品功能：

1. 旧版更新系统遗留清理（详见 `0.6-baseline.md` §2.1）
2. 构建时预置配置系统（详见 `0.6-baseline.md` §2.2）
3. 热更新失败安装包下载兜底（详见 `0.6-baseline.md` §2.3）
4. 社区榜单鉴权与公开首页拆分（详见 `0.6-baseline.md` §2.4）
5. 公开首页宽屏优化与社区聚合预览（详见 `0.6-baseline.md` §2.5）
6. 榜单安全级别与 API 侧匿名化（详见 `0.6-baseline.md` §2.6）
7. 客户端 UX 改进（详见 `0.6-baseline.md` §2.7）
8. 榜单匿名身份语义展示（详见 `0.6-baseline.md` §2.8）
