# AI Token League 0.6 开发任务

## 0. 范围

0.6 已开启两个产品功能：

1. 旧版更新系统遗留清理（详见 `0.6-baseline.md` §2.1）
2. 构建时预置配置系统（详见 `0.6-baseline.md` §2.2）

## 1. 状态值

```text
TODO        未开始
DOING       开发中
BLOCKED     阻塞中
REVIEW      待评审或待验证
DONE        已完成
DEFERRED    延后，不进入当前版本
```
