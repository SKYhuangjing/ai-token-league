# AI Token League 0.5 开发任务

## 0. 范围

0.5.0 已开启三个产品功能：

1. Admin basicAuth（详见 `0.5-baseline.md` §2.1）
2. MIN_CLIENT_ENFORCE 最低客户端版本强制升级（详见 `0.5-baseline.md` §2.2）
3. Admin 设备面板（详见 `0.5-baseline.md` §2.3）
