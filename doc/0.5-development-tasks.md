## 5. 验证

当前已开启功能至少需要以下验证：

```bash
node --check src/desktop/main.cjs
node --check src/desktop/renderer.js
node --check scripts/bump-version.js
bash -n scripts/start-server.sh
npm test
npm run desktop:smoke
git diff --check
```

electron-updater 集成额外验证：

```bash
npm run package:installer:win       # 构建 Windows NSIS 安装器
npm run package:installer:mac:all   # 构建 macOS DMG/ZIP
npm run release:dry-run             # 验证 latest.yml / latest-mac.yml 生成
```

后续新增 0.5.0 任务时，必须先补充对应 baseline 条目和验证矩阵，再进入实现。
