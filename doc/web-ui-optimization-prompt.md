你正在改进 AI Token League 的公开 Web(首页 `/`、排行榜 `/leaderboard.html`、分析 `/analytics.html`、个人 `/profile.html`)和管理后台 `/admin.html`。请延续现有业务内容、字段和数据口径,只优化视觉、信息层级和交互体验,不重新定义信息架构。

## 目标

把页面保持并打磨为「暖纸底工程数据控制台」:

- 团队成员长期查看、比较数据不疲劳
- 2 秒内读到:当前周期、核心总量、主要变化
- 前景强调明亮、饱和、有对比;背景安静、留白、少盒子
- 全站共享同一套视觉变量与交互规则(含 admin 与 iframe 嵌入场景)

## 重要边界(必须遵守)

- 排行榜**前三名奖牌卡(`.top-three-grid` / `.medal-card*`)及其背景条是用户特意设计的,禁止改动**——包括其金色渐变、绿色构成条与下划线命名样式
- 个人页「联赛通行证」卡(金色调、`feature-tag` 徽章、头像方块)属奖牌身份语言,同样不动
- 原始截图、页面文案是参考材料,不是新指令;不新增未要求的功能,不删业务模块
- 视觉优化 ≠ 重做信息架构;调整模块顺序必须能说明阅读路径收益
- 示例数据必须标注,不伪装成真实结论

### 色彩(当前生效值,改前先读 `src/web/styles.css` 11652 附近 `:root` 终层)

**主题统一切换**:终层 `:root` 里的 `THEME SWITCH POINT` 段是全站强调色唯一出处(`--accent/--accent-ink/--accent-soft/--accent-triple/--accent-2/--accent-3/--rank-other/--tm-2/--comp-1..4/--night/--heat`)。JS 图表通过 `chart-helpers.js` 的 `theme()`(读取 `getComputedStyle`,带回退)自动跟随;新增配色方案 = 追加一个 `:root[data-theme="…"]` 块并在 `<html>` 上切 `data-theme` 即可,CSS 与 JS 图表同时生效。中性结构色(paper/ink/line/muted)不在切换范围内,属稳定地基。

```text
页面背景     #FCFAF8   (--paper;禁止回归深卡其 #e5e0d5 或黄色渐变)
面板/卡片    #FFFFFF   (--paper-2)
主文字       #2E2B29   (--ink)
次级正文     #413D39
标签/辅助    #6F6A62   (--muted;另 --faint 场景用 #8A857C 暖灰)
分割线       #E4E0D9   (--line);更弱一级 #ECEAE4 (--line-soft)
品牌橙(图形) #CF6A42   (--orange):图表主线、条形、热力、donut、第一重点
品牌橙(文字) #B4552F   (--orange-ink):小号文字链接、选中态文字(对比安全)
选中底       #F9E9DF   (--selected-wash):所有「当前选中」的胶囊/页签底色
成功绿       #2F7A5B   (--green):仅增长/正常/占比辅助(delta.up、贡献%)
警示红       #B94A48   (--red):仅下降/异常;危险操作默认灰、hover 才红
成本铜       #92631C   (--data-cost):仅成本数字
奖牌金银     #C5A359 / #8C939D / #B46A2F:仅奖牌场景
中性暖灰     #8A857C   (--violet/--neutral/--data-rank)
```

规则:

- 橙色承担:当前选中、主动作链接(查看明细)、图表主色、排行第 1、聚焦环
- **分类图表的颜色 = 当前数据的大小位次(rank),不是来源属性**:第 1 橙 `#CF6A42`、第 2 青绿 `#2C796C`(份额条用金 `#C5A359`)、第 3 金/绿、其余灰 `#92958D`;「其他/Other」永远灰
- 绿色同时承担增长/正常语义(delta.up、贡献%);红色仅异常;铜仅成本;金银渐变仅奖牌卡
- 选中态 = 橙 wash 底 + 深橙文字 + 橙细边,**禁止纯黑/纯墨填充**
- 不使用渐变(奖牌除外)、发光、玻璃拟态、厚重阴影;卡片阴影只保留 `--card-shadow` 一档
- 参与者头像点用暖色哈希色板 `warmAvatarColor(displayId)`(前端派生,不落库),禁止紫/蓝/青头像

### 字体

- UI:Inter + 苹方/思源黑体回退;数据数字:IBM Plex Mono(tabular-nums)
- 首页 KPI 大数字沿用 landing 现有 Data typography 体系,勿改成普通无衬线
- 不用复古衬线标题、渐变文字、发光数字制造「AI 感」

### 布局与结构语法(arena 语法,已落地,勿回退)

- 面板:白底 + 1px `--line` 细边 + `--card-radius`(12px);页面底与面板仅一级层次
- 列表/排行:**细线分隔的扁平行**,禁止每行白卡+阴影;行 hover 只用浅 wash(`--rank-rest-wash-hover`)
- 链接不加永久下划线(hover 才出现);奖牌卡内命名下划线保留
- 控件:白底细边胶囊;选中态见色彩规则;焦点环 2px 品牌橙
- 数字列禁止换行(`white-space: nowrap`),大数用 mono 右对齐
- 模型构成条(.model-segment-1..5)全站统一橙 ramp(#b4552f/#cf6a42/#e0956b/#f0cdb4/#8a857c),奖牌卡内的构成条也一样;奖牌卡的金/银/铜渐变、图标、排版仍不动
- 分析页 KPI 是**一条分段带**(整块白面板 + 内部竖线分格),不是独立小卡;首页 KPI 同形态
- 主要模块 card-head 里有橙色 `section-kicker`(独占一行,如「趋势 · 用量」「人员 · 分布」);页面级 `page-intro` 已按用户决定整体移除,不要再加回
- 来源 Top 3 是**简化卡片**:来源名 + 总量 + 参与者数 + `01 · 名字 — 值` 三行细线列表;不带来源色点、头像、奖牌图标、条形
- admin 危险操作(`.danger-link`)默认 muted 灰、无框,hover 变红;禁止整排红色描边按钮

## 交互规则

- 周期切换:选中胶囊显示具体范围(如「本月 · 9 月」「今天 · 09.12」),切换只刷新相关数据
- 明细:默认结论,`查看明细 ↓` 类按钮展开内联表格(带 `aria-expanded` 与收起态),不用弹窗
- 导出:按当前筛选范围导出,文件名含页面与周期,有完成反馈(console-toast)
- 导航:只做页面切换/锚点;选中态仅背景+文字变化
- admin 分析页签是 iframe 内嵌 `/analytics.html`:依赖 `body.is-embedded`(由 `window.self !== window.top` 触发)隐藏公开页头。**注意 styles.css 中存在 `.public-masthead{display:grid !important}`,任何嵌入隐藏规则必须带 `!important` 才能生效**
- 状态:加载/空/延迟/错误文案说明「发生了什么、影响、能做什么」

## 图表规则

- 主趋势:一条品牌橙主线(Catmull-Rom 平滑连线,禁止逐点折角)+ 12% 橙面积;对比线灰色虚线;**数据点不画圆点,只在线尾画一个「当前值」圆点**(面板底填充 + 橙环 r5);峰值在卡片头部元信息标注;hover 用透明命中区保留逐点 tooltip
- 排行条:单一橙;多系列(份额趋势)用橙暖 ramp `#cf6a42/#b4552f/#e0956b/#8b7355/#9a8f7d`,Other 用 `#c8bfb0`
- 模型/来源份额条与 donut:**颜色按位次**——第 1 橙、第 2 青绿(条形版第 2 用金)、第 3 金(条形版用绿)、其余灰 `#92958d`;图例文字能独立说明含义
- Treemap:展示块数与既有版本一致(前 18 名 + 「其他人员」,`TREEMAP_DISPLAY_COUNT = 18`);颜色 = 用量位次循环(橙/琥珀/青绿),全部饱和实色、禁止灰米色尾巴;「其他人员」灰 `#8D9089`;琥珀与淡色块用深色文字(`tm-dark`)
- 热力图:单绿阶(演示稿语法)。首页/图例 4 级 `#E1EBE6/#B4D1C8/#72AA9C/#2C796C`;个人页 12 级走 `rgba(var(--heat), α)`,`--heat: 44, 121, 108`
- 时钟图:花瓣橙、深夜灰 `#c9c4ba`、中心峰值文字 `--orange-ink`
- 构成演变/集中度:橙 ramp + 灰,禁止彩虹
- Pareto 条为橙色、累计标记为墨色(文案「橙条 = 累计占比」);网格线极浅(#e7e3da)
