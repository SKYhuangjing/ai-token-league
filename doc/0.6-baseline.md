## 1. Baseline State

0.6 admits two product features: Legacy update system cleanup (§2.1), Build-time preset configuration (§2.2).

## 2. Scope

### 2.1 Legacy Update System Cleanup

**Problem**: 0.5.1 引入 electron-updater 后，旧版自定义更新系统代码已废弃，但仍在代码库中。包括 `RELEASE_MANIFEST_PATH` 环境变量、`buildReleaseManifest()`、`validateReleaseManifest()`、`selectUpdateArtifact()`、`selectInstallerArtifact()`、`updateStateFromManifest()` 等函数，以及 `RELEASE_PLATFORMS` / `INSTALLER_PLATFORMS` 常量。服务端仍返回 `manifestUrl` 字段，发布脚本仍上传 `latest.json`。

**Goal**: 清理所有旧版更新系统遗留代码，统一到 electron-updater 的 `latest.yml` / `latest-mac.yml` 机制。

**Boundary**:

- 删除 `RELEASE_MANIFEST_PATH` 环境变量及相关代码
- 删除 `buildReleaseManifest()`、`validateReleaseManifest()`、`selectUpdateArtifact()`、`selectInstallerArtifact()`、`updateStateFromManifest()` 函数
- 删除 `RELEASE_PLATFORMS` / `INSTALLER_PLATFORMS` 常量
- 删除 `latest.json` 上传（发布脚本）
- 删除服务端 `manifestUrl` 字段（`releasePublicConfig()`）
- 前提条件：所有活跃客户端已升级到 0.5.1+

**Privacy / Storage / API impact**:

- Privacy: 无新数据采集
- Storage: 无新表或文件
- API: `/api/release/config` 响应移除 `manifestUrl` 字段

### 2.2 Build-time Preset Configuration

**Problem**: 桌面客户端的默认值（`apiBaseUrl`、`autoRefreshEnabled`、`refreshIntervalMinutes` 等）全部硬编码在 `initConfig()` 中。部署时需要用户手动配置云端地址、开启自动同步等，初始化引导成本高。无法像渠道分发一样，在打包阶段预置一套默认配置。

**Goal**: 提供构建时预置配置能力，打包阶段注入一个 `preset.json`，桌面客户端首次启动时用预置值替代硬编码默认值。仅首次启动生效，用户修改后以用户配置为准。

**Boundary**:

- 新增 `scripts/build-preset.js`：从环境变量读取预置值，生成 `assets/preset.json`
- 新增 `src/shared/preset.js`：运行时加载预置配置的纯函数模块
- 修改 `src/desktop/main.cjs`：在 `ensureDesktopConfig()` 中合并预置值到 `initConfig()`
- 预置字段白名单：`apiBaseUrl`、`nickname`、`autoRefreshEnabled`、`refreshIntervalMinutes`、`silentUpdateMode`、`launchAtLogin`、`publicUpload`、`showEstimatedCost`、`showRawTokens`、`providerEnabled`
- 禁止预置字段（必须运行时生成）：`participantId`、`identityPublicKey`、`identityPrivateKey`、`deviceId`、`createdAt`、`desktopAutoInitialized`
- 环境变量前缀 `PRESET_*`，写入 `env.example`
- `assets/preset.json` 加入 `.gitignore`（构建产物，不提交）
- `npm run preset` 链入 `release:build`，确保每次构建从环境变量重新生成
- 无环境变量时生成空对象 `{}`，不影响默认行为

**Privacy / Storage / API impact**:

- Privacy: 无新数据采集
- Storage: 首次启动时预置值写入 `~/.ai-token-league/config.json`
- API: 无新或变更端点

7. `npm test` 通过
