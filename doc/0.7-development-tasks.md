## 3. 验证命令

```bash
node --check src/desktop/main.cjs
node --check src/desktop/preload.cjs
node --check src/desktop/renderer.js
node --check src/web/download.js
npm test
npm run desktop:smoke
scripts/release.sh --platform current --env env.local --yes
```

0.7.0 反向同步后，新增的 public web 验证点：

- `/` 下载页可从 `/api/release/config` 渲染 installer cards。
- screenshot gallery 可展示 `desktop-client`、`desktop-workdirs`、`desktop-sources` 三张图并支持切换/打开。
- latest updates 只展示 changelog 中带 `[Desktop]`、`[Web]`、`[Desktop, Web]` 的条目。
- board preview 文案根据 `/api/board/summary.identityMode` 切换。
- `npm test` 覆盖 changelog parser 和 board summary identity metadata。

## 4. 发布边界

- 0.7 不改变后端上传契约、MySQL schema 或 release manifest，除非实现时发现真实 UI 数据契约缺口并先回写 baseline。
- 0.7.0 已改变 `/api/board/summary` 的返回 metadata，仅新增 `identityMode` / `identityLabel`，不改变统计字段含义、鉴权边界或 usage 上传契约。
- 0.7 不引入 hourly analytics，除非同时完成数据模型、采集、缓存、渲染和验证。
- 0.7 不把 marketing demo 中的硬编码数据、真实账号或本机路径复制到产品代码。
