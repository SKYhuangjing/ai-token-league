0.7 只开启一个完整产品目标：桌面客户端 UI/UX 重构。验收口径是完整功能落地，不拆一期/二期。

产品基线：`doc/0.7-baseline.md`

## 4. 发布边界

- 0.7 不改变后端上传契约、board API、MySQL schema 或 release manifest，除非实现时发现真实 UI 数据契约缺口并先回写 baseline。
- 0.7 不引入 hourly analytics，除非同时完成数据模型、采集、缓存、渲染和验证。
- 0.7 不把 marketing demo 中的硬编码数据、真实账号或本机路径复制到产品代码。
