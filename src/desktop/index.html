Welcome

Welcome to AI Token League

Track your AI coding token usage and compare with the community. The app scans local usage files from Codex, Claude Code, and Cursor, then aggregates daily token counts.

Your data stays private

  • Prompts and assistant responses are never collected.
  • Source code and file content are never collected.
  • Real file paths are replaced with SHA-256 hashes.
  • Cursor session tokens stay on your computer.
  • Your identity private key never leaves your machine.
