借鉴清单 / 不抄的部分

  • 借：衬线大标题 + 无衬线数据；页面呼吸感；浅轨道 meter；排名灰方块；单强调色。
  • 借：图表不彩虹——系列/热力/涨幅共享同一个 accent。
  • 不抄：冷灰白底（我们保留暖 paper）；蓝链接可弱化；置信 whisker 可选用，非必须。
  • ATL 特例：成本继续铜字；跌幅保留红；奖牌金只用于前三，不做大面积。
